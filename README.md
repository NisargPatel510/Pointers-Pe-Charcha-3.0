# PPC Event – Pointers & Programming Concepts in C

> An online technical session focused on building strong fundamentals in C programming with emphasis on pointers and memory concepts.
---

## Overview
The **PPC (Pointers & Programming Concepts)** event was conducted to help **first-year B.Tech students** develop a clear and practical understanding of pointers in C.  
The session combined conceptual explanations, real-life analogies, live coding, and exam-oriented discussions.

---

## Key Focus Areas
- Pointer fundamentals and arithmetic  
- Pointers with arrays and functions  
- Dynamic memory allocation (`malloc()` vs `calloc()`)  
- Common mistakes and previous year questions
